## About the Project

DevStash is a full-stack developer knowledge hub for saving, organizing, and
searching code snippets, commands, and notes — all in one fast, searchable place.

Built with Next.js, Prisma, and PostgreSQL (Neon), DevStash focuses on a clean,
keyboard-friendly dashboard that keeps your saved items one search away.

### Tech Stack
- **Framework:** Next.js
- **ORM:** Prisma
- **Database:** PostgreSQL (Neon)
- **Styling:** Tailwind CSS
